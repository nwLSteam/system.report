# System Report

This repository contains the source code for **the backend version** of [system.report](https://system.report), a site to check the current status
of the Bungie.net API.

The site is based on React with Next.js, uses the [Bungie.net API](https://bungie-net.github.io/multi/index.html) to 
request data, and SCSS for style.

## Running

To develop, run
```shell
next dev
```
and to deploy, run
```shell
next build
next start
```
